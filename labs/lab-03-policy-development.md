# Lab 03: Policy Development

**Time:** 2 hours | **Frameworks:** ISO 27001 Clause 5.2 and A.5.1, SOC 2 CC1/CC5, HIPAA 164.316

## Objectives
Write clear, enforceable policies that map to requirements and are usable by staff.

## Tasks
1. Copy `templates/policy-template.md`.
2. Write an **Access Control Policy** covering joiner/mover/leaver, least privilege, MFA, privileged access, and quarterly access reviews.
3. Write a one-page **Acceptable Use Policy** for employees.
4. Write an **Incident Response Policy** summary (roles, severity levels, escalation, notification duties).
5. For each policy, list the framework requirements it satisfies.

## Deliverables
Three policies in `my-work/policies/`, each with owner, version, review date, and approval line.

## Self-check
- Does each policy use "must" and "should" consistently?
- Is it separated from procedures (the policy states the rule, the procedure states the steps)?
- Can an auditor test each statement?
