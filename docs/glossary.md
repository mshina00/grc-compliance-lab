# GRC and Security Glossary

| Term | Meaning |
|---|---|
| GRC | Governance, Risk, and Compliance |
| CIA triad | Confidentiality, Integrity, Availability |
| ISMS | Information Security Management System |
| SoA | Statement of Applicability (ISO 27001) |
| BIA | Business Impact Analysis |
| BCP / DRP | Business Continuity Plan / Disaster Recovery Plan |
| RTO / RPO | Recovery Time Objective / Recovery Point Objective |
| KRI / KPI | Key Risk Indicator / Key Performance Indicator |
| PHI / ePHI | Protected Health Information / electronic PHI |
| PII | Personally Identifiable Information |
| CUI / FCI | Controlled Unclassified Information / Federal Contract Information |
| DPIA | Data Protection Impact Assessment |
| ROPA | Record of Processing Activities |
| DSAR | Data Subject Access Request |
| DPO | Data Protection Officer |
| BAA | Business Associate Agreement |
| TPRM | Third-Party Risk Management |
| SLA | Service Level Agreement |
| DPA | Data Processing Agreement (GDPR context) |
| SCC | Standard Contractual Clauses (international data transfers) |
| SSP | System Security Plan |
| POA&M | Plan of Action and Milestones |
| ATO | Authority to Operate |
| 3PAO | Third-Party Assessment Organization (FedRAMP) |
| ITGC | IT General Controls |
| ICFR | Internal Control over Financial Reporting |
| IAM | Identity and Access Management |
| MFA | Multi-Factor Authentication |
| RBAC | Role-Based Access Control |
| PAM | Privileged Access Management |
| SIEM | Security Information and Event Management |
| SOC | Security Operations Center (also System and Organization Controls) |
| EDR | Endpoint Detection and Response |
| DLP | Data Loss Prevention |
| CVE | Common Vulnerabilities and Exposures |
| CVSS | Common Vulnerability Scoring System |
| IR | Incident Response |
| TTX | Tabletop Exercise |
| CAPA | Corrective and Preventive Action |
| Inherent risk | Risk before controls |
| Residual risk | Risk remaining after controls |
| Risk appetite | Amount of risk an organization is willing to pursue |
| Risk tolerance | Acceptable variation around appetite |
| Control | Safeguard that reduces risk (preventive, detective, corrective) |
| Compensating control | Alternative control used when the primary one cannot be met |
